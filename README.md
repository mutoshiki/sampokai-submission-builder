# 山歩会 提出書類作成

山歩会の登山企画について、参加者の決定・全体名簿との安全な照合・企画情報と登山計画の入力・学務提出書類の生成を1つにまとめた、Windows向けローカルデスクトップアプリです。

## 利用の流れ

1. サークル全体名簿（XLSX / XLS / CSV / TSV）を選択する
2. Googleフォームからダウンロードした回答（XLSX / XLS / CSV / TSV）を選択する
3. 今回参加する回答だけを選び、未照合・同姓同名・競合を人が確認する
4. 企画情報と登山計画を入力し、ルート画像を選択またはドロップする
5. 確認画面の不備を修正して「提出書類を作成」を押す
6. 企画ごとの出力フォルダを開く

通常利用にインターネット接続、アカウント、外部API、データベースは不要です。全体名簿とフォーム回答は指定したローカルファイルからその場で読み込み、アプリ内へ複製・保存しません。

## 生成物

実施日と山名から新しいフォルダを作り、同梱した提出テンプレートのコピーへ必要箇所だけを反映します。既存ファイルと同名のフォルダがある場合は `_2`、`_3` のように別フォルダを作ります。

```text
2026-09-12_蝶ヶ岳登山/
  01_蝶ヶ岳登山企画参加者名簿.docx
  02_蝶ヶ岳登山計画書.docx
  02_蝶ヶ岳登山計画書.pdf
  03_蝶ヶ岳_登山等届.docx
```

WordとPDFの生成には、Windowsにインストール済みのMicrosoft WordまたはWord COM互換のWPS Officeを使います。利用できない場合は確認画面でインストール案内を表示し、生成を開始しません。

## 安全な照合

- 学籍番号の一意な完全一致を優先し、氏名と矛盾する場合は自動確定しない
- 学籍番号がない場合は、空白・全角半角などを正規化した氏名の一意な完全一致のみ自動確定する
- 同姓同名、複数候補、未照合、学籍番号と氏名の競合は必ず人が名簿候補を選ぶ
- 類似度による曖昧一致を自動確定しない
- Googleフォーム回答者全員ではなく、今回の参加者として選択した回答だけを出力する
- 同じ名簿メンバーの重複選択、必要情報不足、登山等届へ集計できない学部・性別区分を生成前に止める

参加者名簿は運用責任者の指示により、既定で現住所・本人連絡先・緊急連絡先を記載します。確認画面で、住所と緊急連絡先を空欄にする方式、または3項目すべてを空欄にする方式へ明示的に変更できます。

## セキュリティ

- ネットワーク通信、Google API、AI API、アクセス解析、テレメトリ、クラッシュ送信を実装していない
- TauriのCSPで接続先をアプリ自身とIPCに限定する
- 実行時CDNやWebフォントを使わず、依存物をアプリへ同梱する
- 個人情報をログ・設定・ローカルDBへ保存しない
- 元のテンプレート、全体名簿、フォーム回答を上書きしない
- 書類生成用の一時JSONはOSの一時ファイルとして作り、Rust側の処理終了時に自動削除する

## 技術構成

- Tauri 2 / Rust
- React / TypeScript
- Carbon Design System React
- XLSX / XLS / CSV / TSVのローカル読み込み: Rust（calamine / csv）
- DOCX編集・PDF化: ローカルWord互換COMをPowerShell経由で操作
- 配布形式: Windows NSISインストーラー（ユーザー単位）

## 開発・ビルド

開発者だけが必要な手順です。通常利用者は生成済みインストーラーを実行するだけです。

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm tauri build
```

ビルドPCにはNode.js、RustのMSVC toolchain、Microsoft C++ Build Tools、WebView2が必要です。

資料の調査結果と項目対応は [docs/source-analysis.md](docs/source-analysis.md) に記録しています。
