## 書類生成

実在者を含まない12人・8学部・男女混在の架空データで、次の4ファイルを実生成した。

- 参加者名簿 DOCX: 1ページ、表・罫線・学部行・計12名を維持
- 登山計画書 DOCX: 3ページ、行程・数値・ルート画像・続行不能時対応・装備・緊急連絡先を反映
- 登山計画書 PDF: 3ページ、DOCXと同じ構成でローカル生成
- 登山等届 DOCX: 1ページ、令和日付・代表者・場所・期間・予備日・学部別男女集計を反映

運用責任者の指示を反映した「全項目記載」でも再生成し、参加者名簿の現住所・本人連絡先・緊急連絡先が揃って入ることを確認した。テンプレートの編集用青字は生成コピー内だけ黒へ正規化した。

同じ生成経路を参加者1人でも実行し、該当学部の1行だけへ情報が入り、合計1名・1ページで表が維持されることを確認した。

生成前後で、ルート直下の参加者名簿・登山計画書・登山等届の原本SHA-256が一致し、原本が変更されていないことを確認した。同名企画フォルダがある場合は別名フォルダを作成した。

Word互換COMで生成物DOCXを再度開き、PDFへレンダリングした。各ページを画像化して目視し、表、改ページ、ルート画像位置、文字切れ、人数集計を確認した。
