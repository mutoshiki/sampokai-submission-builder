## 資料間の優先順位

1. 現行Wordテンプレート内の指示
2. `登山計画書の作り方2025.pdf`
3. 参考例PDFと過去完成DOCX
4. 2024年の企画講座

参加者名簿の個人情報欄について、テンプレートは「住所欄と緊急連絡先欄は空白」、参考例PDFは「現住所・連絡先・緊急連絡先は記入しなくてよい」、過去完成例は全欄記載となっている。運用責任者から「本アプリはサークル長等が使うため、住所や連絡先を入れてよい」と明示されたため、この指示をテンプレートの一般案内より優先する。アプリの既定値は現住所・本人連絡先・緊急連絡先の全項目記載とし、出力確認画面で明示する。必要時のみ利用者が「住所・緊急連絡先を空欄」または「3項目すべて空欄」へ変更できる。

## 現行テンプレートの必須要件

### 参加者名簿

- 山名、企画者の学籍番号と氏名、実施日、合計人数
- 人文、教育、経法、理、医、工、農、繊維、その他の学部別参加者
- Word形式で提出
- 現住所・本人連絡先・緊急連絡先は、運用責任者の指示により既定で記載

### 登山計画書

- 団体名、企画者、入山エリア、日時、集合場所、集合時間
- 入山予定時刻、下山予定時刻
- 合計時間、上り、下り、距離
- 地点・時刻・休憩・区間所要時間を含む行程
- 判読可能なルート地図
- 続行不能時の対応またはエスケープルート（未記入だと受理されない可能性あり）
- 必要装備、山に合わせた飲料量
- 管轄警察署、企画者携帯番号、留守本部携帯番号
- 日帰りは15時前後の下山が望ましく、16時を過ぎる計画は警告する
- PDF化して会長と学務へ提出

### 登山等届

- 届出日、代表者の学籍番号・学部・学科または課程・氏名
- 主催者「山歩会」、目的「登山」、場所、実施期間、予備日
- 男女別かつ8学部別の人数と合計
- 顧問教員確認欄と押印欄は空欄のまま残す
- 登山計画書を添付する旨の既存注意を保持する

## 安全な照合規則

1. 学籍番号が双方にあり、一意に完全一致し、氏名が矛盾しない場合だけ「完全一致」にする。
2. 学籍番号がなく、空白・全角半角・大文字小文字を正規化した氏名が一意に一致する場合は「正規化一致」にする。編集距離による類似名は自動確定しない。
3. 同姓同名、複数候補、学籍番号と氏名の矛盾、名簿にない回答者は「確認が必要」にする。
4. 利用者が参加者として選択した回答だけを出力対象にする。回答者全員を参加者とみなさない。
5. 同じ学籍番号または同じ正規化氏名の重複回答を表示し、確定参加者の重複は出力を止める。
6. 全体名簿の行数や特定人物を前提にしない。列はヘッダー候補と値パターンから検出し、利用者が列割当を修正できるようにする。

## 書類生成方式

- 3つのWord原本をTauriのリソースとして同梱し、企画ごとの新規フォルダへコピーしてから編集する。
- Windows標準のPowerShellからローカルのWord互換COMを呼び出し、コピー上の段落、表セル、テキストボックス、画像だけを変更する。
- PDFは同じローカルOfficeのPDF保存機能で生成する。開発環境ではWPS OfficeのWord互換COMで正常に変換できることを確認済み。
- Word互換COMがない場合は生成を開始せず、Microsoft Wordまたは互換Officeのインストールが必要だと案内する。
- 原本、名簿、フォーム回答を上書きしない。外部通信、テレメトリ、クラウド連携、個人情報ログを実装しない。
